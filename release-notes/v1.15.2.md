**New since v1.15.1: clearer documentation — a map of the code, and manuals that stand on their own.** Nothing about how the program looks or behaves has changed. This release rewrites the repository's documentation so that every file is easy to find and every reference can be followed: the engine's README is now a map with one line per file, the repository README maps every folder and document, and the technical manual and the screensaver's README describe the current program without engineering history or references to records outside this repository.

## Documentation

- **A map of the code.** `psss-engine/README.md` now lists every file of the engine — its source, checks, tests, build
  scripts and the screensaver host — with what each one does and which section of the manuals explains it. A check in
  `npm run verify` keeps it complete: a new file without a line, or a line for a file that is gone, fails the build.
- **A map of the repository.** Section 1 of the repository's `README.md` lists every folder and document, with what each
  is for and when to read it.
- **The technical manual stands on its own.** Its appendix of preconditions — *what each control needs in order to do
  anything* — now describes the current program only; references into an older edition of the manual, dates and
  development history are gone. A new note in the chapter on the original preset format records the one difference
  between this engine's copy of the original presets and the author's: six presets without any modulation rotate faster.
- **The screensaver's README** is rewritten as a current guide to building, installing and launching it, including why a
  typed argument after `psss.scr` never arrives and how to pass one anyway.
- **`ENGINEERING-NOTES.md`** explains every kind of reference the source comments make to the project's private
  engineering records, so a reader knows that nothing needed to understand the code is missing.

## For developers

- The browser tests run on their **own development server on port 5176**, so a test run no longer slows down a server
  you are using to look at the program; `npm run verify:browser:chunks` runs the full suite in groups, each on a fresh
  server.
- Five unused files were removed from the engine (four empty re-export modules and an unreferenced icon sheet).
- Building the distribution archive now keeps only the newest archive in the repository root.
