**Lava Flow and the other flow-force presets run smoothly.** The Translation Map force is now read back from the graphics card at a quarter of the resolution, so each read moves a sixteenth of the data; on the test machine **Lava Flow** went from 55 to 98 fps and its worst frames from 92 ms to 25 ms.

## Fixed

- **Remaining stalls on the presets with a Translation Map flow force** — **Lava Flow**, **Rising Inferno**,
  **Firestorm**, **Smoke Cathedral**, **Imploding Sun** and **Age Gate Embers**. Version 1.8.8 stopped the frame
  from waiting for the graphics card, but each read still moved the whole screen's force field, about 32 MB every
  few frames. The field is smooth, so it is now averaged over small blocks on the graphics card first and read at
  a quarter of the resolution, about 2 MB. Measured on the test machine with the performance test reel
  (`?reel=2`): **Lava Flow** 55 → 98 fps, slowest frames (p95) 50 → 17 ms, worst frame 92 → 25 ms. The force is
  the same; only the finest swirl filaments can differ slightly.
