Fixes for the Composer's self-similar-curve controls: consistent styling and a logarithmic *Descend* slider.

## Fixed

- **The Composer's self-similar-curve controls** were plain browser widgets beside the styled wave
  controls. They now look and behave like every other row in the tab.
- **The *Descend* slider** has a logarithmic track. It used to be correct at both ends and wrong in
  between, because octaves multiply.

## Downloads

- `psss.scr`: the Windows screensaver.
- `psss-engine-v2-distribution_*.zip`: the web build, the screensaver and both manuals.
- `psss-engine-v2_how_to_use_it.pdf` and `psss-engine-v2_how_it_works.pdf`: the manuals.
