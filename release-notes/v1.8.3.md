**New since v1.7.0: the Fractal Fold, smoother running on slower machines, and a performance readout.** Fold any figure into nested, self-similar structure; the main view now stays smooth while the preview grid animates only as much as the machine allows; and `?perf=1` shows what each part of the picture costs on your own machine. Four new demo presets show the fold.

## The Fractal Fold

A new effect in *Visual FX → Deformation*, below Inversion. It folds the figure back into itself again and again and
pulls every fold back toward where each point started, so a smooth figure turns into **nested, self-similar
structure** — rings within rings, layered shells, a boxy frame, a spiky star.

- **Fractal Fold** — 1 to 3 folds; Off changes nothing.
- **Fractal Cell** — the size of the invisible box the figure is folded into; it picks the family of shapes, and
  small changes morph smoothly.
- **Fractal Scale** — how strongly each fold stretches the figure; negative values turn it inside out as well, and
  0 leaves the figure exactly as it is.
- **Cell Breath / Cell Rate** and **Scale Breath / Scale Rate** make the cell and the strength swing by themselves.

It folds across the screen only, so near and far are never swapped and depth shading stays right, and the figure
keeps its own size. It works on wave figures, self-similar curves and attractors alike.

### The demo presets

All four are at the end of the library; load each one's base preset beside it to see what the fold does.

| Preset | What to watch for |
|---|---|
| **Fractal Cross** | `Cycloid`'s ring of loops folded into a glowing four-armed cross, drawn as LiquidLight splats |
| **Fractal Butterfly** | `Quader`'s ring folded into soft lobes, in the Pastel palette |
| **Fractal Star** | one strong fold into a crimson spiky star whose spikes reach and recede |
| **Fractal Lattice** | the Hilbert 3-D curve folded into a jagged prismatic architecture |

## Smoother on slower machines

- **The preview grid no longer holds up the main view.** The thumbnails used to make the graphics card finish all of
  its work, the main view's included, once for every thumbnail. Measured on a slow graphics setup, the main view
  lost 30–50 % of its frame rate to the grid; it now loses 7–16 %.
- **The main view comes first.** The thumbnails animate with whatever time the main view leaves free: fully when it
  keeps up with the screen, less as it falls behind, and not at all when it is struggling — but **every thumbnail
  still shows its picture**.
- **`?perf=1` shows what it costs on your machine.** Add it to the address for a small readout: the main view's
  frames per second and frame times, the time each part of the frame takes on the processor and (where the browser
  can measure it) on the graphics card, and how much each thumbnail grid draws. The user manual's section 4.3, *If
  it runs slowly*, explains every line.

## Smaller changes in this release

- **Each visit starts on a different preset**, chosen at random from the library. To start on a particular one, add
  `?preset=` and its name to the address, e.g. `index.html?preset=Quader`.
- **Composer → Apply Visual FX** now switches off the Deformation operators too (Symmetry, 3-D Symmetry, Twist,
  Taper, Bend, Fold, Inversion, Fractal Fold, 4D) and the per-particle spreads, so it really shows the figure without
  any Visual FX, as it always promised.
