**Less work per frame on every machine, and a built-in performance test.** Curl-noise presets compute their swirl two to four times faster, every frame is one full-screen pass lighter, the particle upload to the graphics card sends only what is drawn, and the page asks for the faster graphics card on machines that have two. Add `?reel=2` to the address to measure any machine the same way and get a log file.

## Faster

- **Curl noise** — the swirling flow on presets such as **Video Tape Error**, **Modern Art III** and **Mind Sight** —
  is now computed exactly rather than estimated: three noise evaluations per particle instead of twelve. Those
  presets compute their figure 2–4× faster. The flow is the same, except that a handful of particles no longer
  jump for a single frame, which was an artefact of the old estimate.
- **The trail fades in one pass** instead of two. Every frame, on every preset, the graphics card writes the full
  screen once less.
- **Only what is drawn is sent to the graphics card.** Particle data that no draw reads, or that has not changed,
  is no longer uploaded every frame. This matters most on machines whose processor is the limit.
- **The faster graphics card is requested.** On laptops with both an integrated and a dedicated graphics card, the
  browser is now asked for the dedicated one. This can use more battery while the page is open.
- **No extra copy of each frame.** The page no longer asks the browser to keep a copy of every frame it shows.

Nothing looks different: compared frame by frame against the previous version, the pictures are identical or
differ only by rounding.

## The performance test reel (`?reel=2`)

Add `?reel=2` to the address, for example `https://alassio.github.io/psss-v2/?reel=2`, or `index.html?reel=2`
from the downloaded files:

1. A fixed test reel of 18 presets starts, covering every kind of cost: light and heavy figures, glowing splats,
   smoke, liquid, Neon Lines, curl noise and the field effects.
2. **Click once** to go full screen. Measuring happens only in full screen.
3. Each preset plays for 16 seconds: the short freeze when it appears is recorded, then it settles for 10 seconds
   and is measured for 5. The line in the bottom-left corner shows the progress. It takes about six minutes.
4. At the end a text file named `psss-perf-…txt` is **downloaded**, and the same log is shown with a **Copy**
   button. It lists the machine's graphics card, processor threads, screen and refresh rate, and for every preset
   its frame rate, frame times, the freeze when it appeared, and the processor and graphics time of each part of
   the frame.

The user manual's section 4.3, *If it runs slowly*, describes it.
