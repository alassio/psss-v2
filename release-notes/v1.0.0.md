The first public release of **PSSS V2**: a TypeScript + WebGL2 rewrite of PSSS, the particle systems
screensaver created by Andreas Kardin (*mephzara*).

3D particles travel along modulated sine waves (3D Lissajous figures), and the engine projects, trails,
warps and colour-grades them. It runs in a browser, and on Windows it also installs as a real
screensaver.

## What's in it

- **The engine and a library of 325 presets.** Every preset of the original JavaScript version still
  loads unchanged.
- **The Synthesis Lab**, the full control surface: Reel, Visual FX, Materials, Composer, Transmap,
  Sliders, Mixer, Randomise, Evolution and History.
- **A preview grid** with a live animated tile for every preset.
- **The Reel**: a playlist of presets played full screen, with black or cross-fade transitions.
- **The Windows screensaver** (`psss.scr`): a single self-contained binary that plays your main reel on
  the primary monitor and blacks out the others. Its *Configure* button opens the engine's own Reel
  editor.

## Downloads

- `psss.scr`: the Windows screensaver. Section 4.2 of the user manual, *Run it as a screensaver*,
  walks through the install.
- `psss-engine-v2-distribution_*.zip`: the web build, the screensaver and both manuals together.
- `psss-engine-v2_how_to_use_it.pdf`: the user manual.
- `psss-engine-v2_how_it_works.pdf`: the technical reference.
