**New since the first public release: a second figure type, self-similar curves.** Alongside the wave figures, PSSS now draws fractal curves built from thirteen production rules (Hilbert, dragon, Koch, Gosper, Moore and more), with fourteen demo presets to start from.

## New figure type: self-similar curves

A preset can now draw a **self-similar curve** instead of the sum of sine waves: a path built by
repeating a production rule until it fills a line, a plane or a cube. Choose the figure type at the top
of the **Composer**.

- **Thirteen rules:** Hilbert 2D and 3D, Dragon, Terdragon, Koch quadratic, Sierpiński arrowhead,
  Gosper, Plant, Moore, Peano, Lévy C, Sierpiński–Knopp and Bush 3D.
- **Alive, not static:** three independent turning angles, a continuously changing recursion depth (new
  detail grows *between* the existing strokes) and *Descend*, a zoom that travels into the curve.
- **One figure becomes another.** The angle is not part of the rule, so sweeping it morphs between named
  fractals: the Koch production at 90° is the Koch curve, and at 117° it is a Sierpiński triangle.
- **Everything else works on it:** the particles, trails, ribbons, colour sources, deformation, field
  systems, image warp and grading all apply unchanged.
- **Switching type loses nothing.** A preset keeps the settings of both types, so switching back restores
  the figure exactly.

### The demo presets

All fourteen are at the end of the library; type *Curve* into the grid's *Search presets…* box to show just these.

| Preset | Rule | What to watch for |
|---|---|---|
| **Curve Lattice** | Hilbert 3D | the reference figure: the lattice held almost still, its colour following the path |
| **Curve Subdivide** | Hilbert 3D | the recursion breathing — detail appears between the strokes and recedes again |
| **Curve Tilt** | Hilbert 3D | all three turning angles breathing independently |
| **Curve Volume** | Hilbert 3D | the curve read as a glowing coloured volume rather than a line |
| **Curve Descent** | Hilbert 3D | the self-similar zoom: travelling into the curve as detail opens ahead |
| **Curve Plane Dive** | Hilbert 2D | the same zoom on a flat curve, read as a plane |
| **Curve Morph** | Koch quadratic | the Koch curve opening into a Sierpiński triangle and back |
| **Curve Gasket** | Sierpiński arrowhead | the Sierpiński triangle drawn by a single path |
| **Curve Island** | Gosper | the Gosper island's fractal coastline, relaxed into a smooth shore |
| **Curve Thicket** | Plant | a branching tree, coloured by branch |
| **Curve Weave** | Moore | the only closed curve: a loop that fills the square |
| **Curve Triad** | Terdragon | the triangular-grid texture no other figure can make |
| **Curve Dragonfold** | Dragon | the Heighway dragon, the paper-folding curve |
| **Curve Scroll** | Lévy C | a self-overlapping curve drifting in a slow flow |

## Also new since v1.0.0

- **Find a setting.** A search field in the Synthesis Lab's header finds any control in any tab by name,
  tooltip or value, and jumps to it.
- **Correct depth cues.** Depth brightness and depth colour shift pointed the wrong way, so near looked
  dimmer and cooler. All depth cues now agree, and near is near.

## Smaller changes in this release

- **Mixer:** after *Figure from B, look from A* (or the reverse) the crossfader still works — it now
  fades only the part you took. A new **All ⇄** button hands every row back to the crossfader, and the
  crossfader is greyed out when no row follows it.
- **Screensaver:** shows its version in the Settings window's title and in Windows under right-click
  `psss.scr` → Properties → Details.
- **Eleven of the curve demos retuned.**
